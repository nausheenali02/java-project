# 📝 Java To-Do List Application

A simple and efficient To-Do List application built using Java. This project allows users to manage daily tasks by adding, viewing, updating, and deleting tasks through a user-friendly interface.

---

## 🚀 Features

- ➕ Add new tasks  
- 📋 View all tasks  
- ✏️ Update existing tasks  
- ❌ Delete tasks  
- ✅ Mark tasks as completed  

---

## 🛠️ Technologies Used

- Java (Core Java / OOP)
- Java Collections (ArrayList)
- File Handling (for saving tasks)
